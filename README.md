# TechCenter

Página estática de servicios informáticos y venta de hardware en Guatemala. Es un ejercicio de la clase de INTECAP: presentación del taller, servicios, recomendaciones de cuidado del equipo, galería y formulario de contacto.

## Qué incluye

- Barra de navegación fija con acceso a cada sección
- Servicios: reparación, ensamble de PC y redes
- Recomendaciones en un acordeón
- Galería de equipos y proyectos
- Formulario de contacto (se muestra un aviso al enviar; no guarda datos)
- Modo claro y oscuro, con la preferencia guardada en el navegador

## Tecnologías

- HTML
- CSS
- Bootstrap 5 (CDN)
- JavaScript

## Cómo verla

Abre `index.html` en el navegador. No hace falta instalar nada ni levantar un servidor.

## Estructura

```text
.
├── index.html
├── README.md
├── css/
│   └── estilos.css
└── js/
    └── noche.js
```

- `index.html`: estructura de la página
- `css/estilos.css`: estilos propios, cargados después de Bootstrap
- `js/noche.js`: modo claro/oscuro y comportamiento del formulario
